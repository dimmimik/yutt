# Architecture

## Components

- Repository
- Services
- Renderer
- Utilities
- Configuration

## Flow

```
JSON Data
     ↓
Repository
     ↓
TransferService
     ↓
StatisticsService
     ↓
Renderer
     ↓
Console / Report
```

## Supported Networks

- Ethereum
- Base
- Arbitrum
- Polygon

The architecture separates business logic from visualization.
